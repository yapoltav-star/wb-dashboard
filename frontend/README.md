# Интерфейс

`index.html` — страница дашборда. Сохраняй такую же копию в
`backend/frontend/index.html`: деплой с корнем репозитория копирует исходник,
а деплой с корнем backend использует вложенную копию.

«Позиции → История бустов» — даты сравнения, фильтр артикула/ключа, поиск,
внешние и собственные полки, покрытие по дням и список исключённых заданий.
Раздел читает серверную историю; ручной замер не заменяет успешные снимки дня.
