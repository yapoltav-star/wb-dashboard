# WB Dashboard

Рабочий дашборд одного кабинета WB: FastAPI, Supabase и статическая страница.
Настройка и переменные окружения: [SETUP.md](SETUP.md).

- [backend](backend/README.md) — API, загрузки, серверные расписания.
- [frontend](frontend/README.md) — исходная страница интерфейса.
- [tests](tests/README.md) — проверки расчётов и сохранения данных.
- `supabase/schema.sql` — базовая схема.
- `docs/team/README.md` — материалы команды.

История бустов находится в «Позиции → История бустов». С 23 ноября 2026
отслеживаются 34 товара из boost-report.xlsx за 16–22 ноября: 89 поисковых
связок и 112 пар товар/полка (30 источников, из них 5 собственных).
