# Проверки

`python3 -m unittest discover -s tests -p 'test_*.py'`

`test_boost_monitor.py` проверяет перезапуск, повтор ошибок, неизменность
успешного дня, сбои чтения/записи, границы дат МСК, неполную выдачу,
несопоставимые полки, точные места и конфигурацию из отчёта Boost.
Остальные тесты проверяют каталог, воронку и рабочее место рейтингов.
