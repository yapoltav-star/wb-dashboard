# Телеграм-бот к дашборду

Бот живёт внутри того же процесса, что и бэкенд на Railway. Отдельный сервер покупать
не нужно: Railway уже хостится за рубежом, а это единственное, ради чего в гайдах
советуют брать Хорька или Vultr.

Бот работает **только на чтение**. Он ходит в те же функции, что и сайт, и ничего
не меняет ни в Wildberries, ни в Ozon, ни в Supabase.

## Запуск за пять минут

**1. Создать бота.** В телеграме написать [@BotFather](https://t.me/BotFather), команда
`/newbot`, придумать имя. В ответ придёт токен вида `12345:AAH...`.

**2. Положить токен в Railway.** Variables → добавить:

```
TELEGRAM_BOT_TOKEN=12345:AAH...
```

**3. Узнать свой chat_id.** После редеплоя написать боту любое сообщение. Он ответит
готовой строкой с твоим id, потому что белый список ещё пуст.

**4. Закрыть доступ.** Добавить в Variables:

```
TELEGRAM_ALLOWED_CHAT_IDS=123456789
```

Несколько человек — через запятую. Все, кого нет в списке, игнорируются молча.
Этот шаг обязателен: без него бота может использовать любой, кто узнает его имя.

**5. Опционально — вопросы обычным текстом.** Без этого работают только команды.
Подойдёт ключ OpenAI или Anthropic, любой один:

```
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o
```

или

```
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-sonnet-4-5
```

Если заданы оба, по умолчанию берётся OpenAI; переключить можно через
`LLM_PROVIDER=anthropic`.

Запросы к модели уходят с сервера Railway, а он за рубежом, поэтому блокировок
для российского IP тут нет. Если в ответ прилетит ошибка 404 с упоминанием модели,
значит её имя устарело — актуальное видно в консоли провайдера, подставить в
`OPENAI_MODEL` или `ANTHROPIC_MODEL`. Бот показывает такие ошибки прямо в чат.

## Проверка

`GET /api/telegram-status` показывает, что настроено, не раскрывая секретов:

```json
{"token_set": true, "whitelist_configured": true, "polling": true,
 "llm_provider": "openai", "model": "gpt-4o"}
```

Если `polling` равен `false`, бот не поднялся — смотреть логи Railway.

## Команды

| Команда | Что показывает |
|---|---|
| `/stock` | Что закончится в ближайшие 14 дней, с запасом в днях |
| `/stock 042` | Остаток, склады и продажи по конкретному артикулу |
| `/sales` | Топ продаж за 7 дней с разбивкой вчера / 7 / 28 дней |
| `/geo` | География заказов за 28 дней: склады отгрузки и регионы |
| `/geo 7 fbs` | То же за 7 дней и только по FBS |
| `/fbs` | Скорость отгрузки, пороги kC, бонусы и штрафы в рублях |
| `/sklad` | Остатки на собственном складе |
| `/reset` | Забыть контекст разговора |

Если задан `ANTHROPIC_API_KEY`, можно просто спрашивать словами: «что заканчивается
из золотых», «сколько заказов из Казани за неделю», «какая медиана отгрузки». Модель
сама выберет нужные данные из тех же источников.

## Что внутри

Код в `backend/telegram_bot.py`, подключение — в конце `backend/main.py`. Бэкенд
передаёт боту словарь функций чтения, поэтому модуль не зависит от `main.py` напрямую
и его можно тестировать отдельно.

Данные забираются через long polling, никакого публичного вебхука настраивать не надо.
Если токен не задан, модуль тихо не запускается и на работу сайта никак не влияет.

Инструменты, доступные модели: товары и остатки, география заказов, скорость FBS,
темп продаж, собственный склад. Все — только чтение. Запись намеренно не подключена:
бот в телеграме с правами на изменение цен — это возможность уронить кабинет одним
неудачным сообщением.
