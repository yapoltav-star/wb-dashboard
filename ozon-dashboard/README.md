# Ozon dashboard scaffold

Папка `ozon-dashboard/` — заготовка **отдельного** дашборда Ozon (не часть WB-сайта).

Как пользоваться:
1. Прочитай `ozon-dashboard/SETUP.md`
2. Вынеси содержимое `ozon-dashboard/` в свой репозиторий `ozon-dashboard` (или задеплой Root Directory = `ozon-dashboard/backend`)
3. Накати `supabase/schema.sql`, задай `OZON_CLIENT_ID` / `OZON_API_KEY` / Supabase

WB-дашборд в корне репо не трогали.
